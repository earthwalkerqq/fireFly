# Тест триангуляции Делоне на модели «пластина с отверстием»

Автономный тест функции `delaunay_triangulation()` из проекта firefly,
доказывающий её применимость в качестве генератора конечно-элементной
сетки.

## Что тестируется

Классическая для МКЭ модель — квадратная пластина **100×100** с круглым
отверстием **R = 20** в центре (многосвязная область).

Тест:

1. читает точки из `points.txt` (расставлены по контуру пластины,
   контуру отверстия, в узком кольце вокруг него и по внутренней
   сетке);
2. строит триангуляцию проектным алгоритмом Боуйера — Ватсона;
3. удаляет треугольники, центроид которых попал в отверстие
   (стандартная постобработка для многосвязных областей);
4. **проверяет условие Делоне** — для каждого треугольника
   контролирует, что в его описанной окружности нет ни одной из
   остальных точек;
5. считает статистику качества (минимальные углы, гистограмма),
   которая определяет численную устойчивость МКЭ-расчётов.

## Что нужно для запуска

* C-компилятор с поддержкой C11 и `-pthread`;
* python3 (для генерации `points.txt`).

OpenGL/GLFW/cglm **не требуются** — тест собирается только из
`src/triangulation.c` и `src/opencl.c` (в stub-режиме).

## Сборка и запуск

```
python3 gen_points.py       # сгенерировать points.txt
make                        # собрать test_triangle
./test_triangle             # запустить — пишет stats.txt и result.svg
```

Либо одной командой: `make run`.

## Результат

* `points.txt` — точки модели (≈ 180 точек).
* `stats.txt` — текстовый отчёт: число точек/треугольников, результат
  проверки условия Делоне, статистика углов и гистограмма.
* `result.svg` — визуализация КЭ-сетки. Цвет треугольника отражает
  минимальный угол: зелёный — ≥ 30°, жёлтый — 20–30°, оранжевый —
  10–20°, красный — < 10°. Внешний квадрат и окружность —
  справочные линии контура пластины и отверстия.

Типичный результат:

```
Прочитано точек: 177
Треугольников КЭ-сетки: 294
Условие Делоне: ВЫПОЛНЕНО (0 нарушений из 312 треугольников)
наихудший мин. угол: ~6°  (сливеры на границе с отверстием)
средний мин. угол:   ~42° (хорошее качество для МКЭ)
```

## Что это доказывает

* **Корректность.** Все построенные треугольники удовлетворяют
  условию Делоне — описанная окружность пуста. Это формальная
  проверка правильности алгоритма.
* **Пригодность для МКЭ.** Триангуляция Делоне обладает известным
  свойством максимизации минимального угла: ни одна другая
  триангуляция данного набора точек не даст лучшего наихудшего
  угла. Это напрямую отвечает требованиям МКЭ к численной
  устойчивости расчёта.
* **Работа с многосвязной областью.** После удаления треугольников
  с центроидом внутри отверстия получается корректная КЭ-сетка
  пластины с отверстием.

Сливеры (треугольники с малым минимальным углом) возникают у границы
отверстия в местах, где обычная (неограниченная) триангуляция Делоне
строит косые соединения между точками контура и кольца. Их количество
мало (единицы из сотен), они не нарушают условие Делоне и для
типовых МКЭ-задач отбраковываются на этапе подготовки сетки. Полностью
их устранить можно переходом к ограниченной (constrained) триангуляции
Делоне или измельчению по Рупперту — это самостоятельная задача за
рамками данного теста.
